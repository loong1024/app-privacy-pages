学习进度保存在哪里？

全部保存在你的设备本机。卸载应用会删除进度。建议定期在 我的 → 数据导出 生成 JSON 备份文件，导出的文件可随时通过 数据导入 恢复或迁移到新设备。

换新手机怎么办？

在旧设备上 我的 → 数据导出，把导出的 JSON 文件（例如通过隔空投送、iCloud Drive 或微信传输）带到新设备，安装 AI日课后在 我的 → 数据导入 选择该文件，进度即可完整恢复。

应用怎么收费？

学习内容免费，解锁全部动手实验包需一次性内购 $2.99，无订阅、无广告。支付由 Apple 处理；在 App Store 的购买记录里可以查看凭证。若更换设备后提示重新购买，请确认登录的是购买时使用的同一 Apple ID，或在 App Store 账户设置中「恢复购买」。

为什么内容不会过期？

除热榜内容（90 天时效、过期自动归档）外，题库与概念卡随应用内置、永久可用；48 个实验的 GitHub 实战包经一次性内购解锁后永久可用。热榜内容会在应用更新时替换为新的 90 天批次。
